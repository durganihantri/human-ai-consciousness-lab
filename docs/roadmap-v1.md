# Public Research Prototype Roadmap

## Milestone A — Documentation (present)
Research questions, 14-entry scoping literature map, design proposals, measurement drafts, scale-applicability desk review, and ethics limitations. These are not a systematic review or validated instruments.

## Milestone B — Technical prototype (in progress)
Three synthetic stimulus pairs, local browser demonstration, reproducible synthetic pipeline, automated tests, and CI. Acceptance requires a successful GitHub Actions run plus manual browser checks.

## Milestone C — Collaborative review (next)
Invite independent methodologists to review item validity, confounds, language, accessibility, and reproducibility. Track decisions and disagreements in Issues. No coauthorship promise.

## Milestone D — Human research (future, separately gated)
Ethics determination, instrument refinement, preregistration, sample/power planning, consent, data-management safeguards, and only then participant recruitment. No completion date is asserted.

## Proposed starter Issues
1. Review 01A stimulus pairs for pronoun-versus-authority confounding.
2. Compare agency/experience instruments and reuse permissions.
3. Audit Safari local-file compatibility and accessibility.
4. Design an appropriate power/simulation plan for a future study.
5. Review English–Mandarin translation and construct invariance requirements.
